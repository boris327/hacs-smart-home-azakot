# amp — example site

אתר סטטי לדוגמה שנבנה לפי ה-**amp Style Reference**: כתום חם אחד על קנבס אכרומטי, טיפוגרפיה של משפחת גופנים אחת, ומוצר אחד כגיבור הדף.

> זהו אתר הדגמה בלבד ואינו חלק מאינטגרציית `smart_home_azakot`. אין לו תלות בקוד ה-Home Assistant שבריפו.

## קבצים

| קובץ | תיאור |
|------|-------|
| `index.html` | דף הנחיתה — hero, press strip, כרטיסי פיצ'רים, "How to use", דארק band, מפרט, טופס הרשמה, פוטר |
| `styleguide.html` | טוקנים, סקאלת טיפוגרפיה, קומפוננטות, סולם משטחים, Do & Don't |
| `styles.css` | כל הטוקנים והקומפוננטות. אין תלויות חיצוניות |

## הרצה

```bash
cd site
python3 -m http.server 8000
# http://localhost:8000
```

## עקרונות שהאתר מיישם

- **כתום מדוד** — `#ff6105` מופיע רק ב-CTA הראשי, בתג הצעד הפעיל, בקו ההדגשה ובמשיכות מותג.
- **סולם רדיוסים** — כרטיסים 5px, תמונות 8px, כפתור משני 24px, CTA ראשי ושדות קלט 50px, ניווט 40px.
- **הצללה יחידה** — ה-glow הכתום (`rgba(255,97,5,.6) 1px 6px 14px`) שמור ל-CTA הראשי בלבד.
- **טיפוגרפיה** — משקלים 300/400/500 בלבד; ה-tracking מתהדק ככל שהגודל גדל (`-0.036em` בדיספליי, אפס בגוף).
- **סולם משטחים** — `#ffffff → #f3f4f3 → #e5e7eb → #ffdfcd → #202120`.

הגופן `PublicaSans` אינו מצורף; ה-stack נופל ל-`Inter` ואז ל-`system-ui`, כך שהאתר עובד גם ללא רשת.
